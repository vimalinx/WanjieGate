# REVIEW-0002 · 参考研究后的本地改动

日期：2026-09-27；整理与实现：Wilson；来源：vimalinx 本轮转贴研究及明确要求委派子代理核对。转贴内容不归为 kanemaverick 的观点，尚未收到他的提案。

## 本轮选择

保留 Python 标准库运行时与原生 JS。外部框架通过适配器评估；本轮未引入其依赖或复制第三方代码。来源与许可证单列于 [研究记录](../research/0001-reference-implementations.md)。

### 输入与任务归属

`static/runtime-app.js` 在语义请求前冻结 intent、输入版本与文本；异步取消之后、任务受理之后再次核对。过期任务发回原意图取消，不能挂到当前意图。输入变更立即取消已跟踪任务，清空旧候选展示。候选仅展示当前语义任务因果链里的建议。意图切换仍允许原意图的已发起工作留在原空间，不搬移结果。

### 读取深度独立于工作集热度

`context.set.detail` 提供 full / excerpt / metadata，默认 full；与 HOT/WARM/COLD 正交。片段保留原文字、明确标记截断，目录只提供已有元数据，不进行自动摘要。原 Artifact 不改写。Context 项保存版本、读取深度、原始成本与实际成本。预算不足明确排除，不默默裁剪。UI 工作集页可指定范围。

### 状态与执行保护

- 排队任务先确认上下文和读取范围仍有效，再消耗授权次数。
- 语义提交时检查内容版本与读取范围，旧判断留在日志中但不驱动策略。
- 组合步骤非零退出停止后续步骤；已经产生的内容保留，标为部分结果。

上述改动已经写入源码，最后这批尚未重新运行测试或浏览器验证。[前段运行证据及边界](../../docs/acceptance-runtime-v01.md) 单独记录。
