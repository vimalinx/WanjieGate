## 实现范围

源码入口见 [README](../README.md) 和 [协议](../protocol/v0.1/README.md)。本轮实现本地持久 Intent、四种类型化消息、模块与能力登记、权限、执行、工作集、关系、视图与因果追踪。外部系统接入见 [交接](runtime-integration-handoff.md)。这不是全部桌面愿景的验收声明。

## 已取得的证据

本轮前段回归记录：57 项 Python 测试通过，另有 3 组 Node 断言通过（组合、实时调度、命令响应丢失恢复）。隔离数据库与可控生成/语义提供者用于回归；这些结果不代表真实云端生成成功。

实际本机隔离 Python 执行输出 25，进程内不可见 `/home/vimalinx`。依赖 bubblewrap / prlimit；不可用时明确失败，不降级为宿主执行。

浏览器使用独立端口 5174 和 `.ai/test-data/intent-runtime-browser` 数据目录，已实际操作：

- 创建意图，导入两行数据 10、15，分析显示合计 25、均值 12.5、行数 2。
- 将原数据改为 COLD：退出当前展示与上下文，分析保留，原数据仍可在工作集中管理。
- 保存、编辑、固定笔记，创建独立分支，返回原意图并刷新，文字与固定状态保留。
- 浏览器错误日志为空。
- KEV 连接失败被明确显示；没有用本地规则假装模型调用成功。

浏览器发现客户端未提供可选 correlationId 时执行失败；Kernel 已补全根消息 correlationId，并加入对应回归。生命周期消息样例通过 CLI 校验。
