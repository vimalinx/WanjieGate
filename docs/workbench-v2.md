# 万界门：意图工作台

## 产品契约

输入直接形成实时交互界面，生成按钮启动云端执行，产物保留上下文。一个目的可以同时需要数据、文稿和任务；新判断不能移除已经编辑或固定的产物。没有数据时明确索取，不把演示数据当成用户数据。

## 边界

- `static/registry.json`：能力与组件的声明，输入输出类型、成本、布局和依赖。
- `backend/composition.py`：独立多标签判断、能力依赖图、组件选择与稳定性策略。
- `backend/providers.py`：本机 KEV 与 LocalRouter 生成服务；凭据不进入浏览器。
- `backend/store.py`：SQLite 持久工作区、产物、执行记录、版本。
- `backend/scheduler.py`：有界后台任务、幂等提交、取消、阶段进展和执行闭环。
- `backend/server.py`：同源 API、静态页面、输入校验与导出。
- `static/js/`：状态、API、预览选择、组件渲染和交互，各自独立。

## 决策与组合

1. 本地规则给即时预览；每次输入立即调度 KEV 对各能力分别回答 noul，不再用一个互斥场景代表任务。
2. KEV 只看当前目的与资源摘要。显式请求是下限，模型可以增加相关能力；不可用输入形成待补充状态。
3. 已选能力按类型依赖组合：数据统计 → 文稿 → 任务。纯任务规划和纯写作也可独立执行。无专门能力时使用回答能力。
4. 组件效用由能力相关性、已有产物、固定状态与操作焦点共同决定；预览有预算，真实产物不被预算裁掉。预览候选变化采用迟滞。
5. 发送端使用已选择的预览计划并在服务端重建白名单依赖；浏览器不能指定任意函数、URL 或 shell。

## 三个时钟

- 输入、尺寸、选中状态：本地即时。
- 意图：串行 KEV，忙时返回本地判断；有界缓存，过期响应丢弃。
- 执行：后台任务 + 递增事件序列；前端轮询任务进度，阶段完成即呈现产物，不等全部结束。

## 数据与执行

本地可完成：粘贴 CSV / 文本、数据统计与图表、任务勾选、文稿编辑、保存、Markdown 导出。生成通过 `lr exec` 调用已发布服务，每次真实调用保存私有回执且不自动重试。初始配置选择 `llm7: minimax-m2.7`，部署者可用环境变量设置 pack/model；每次调用精确核对目录并预检。

发送到生成服务的数据限定为本工作区当前输入与关联内容；输入框旁有本地 / 云端标识。取消阻止后续步骤与写回，已经发出的上游请求不宣称已撤回。服务重启把未结束任务标记为 interrupted，禁止自动重放。

## 视觉

暖白画布、墨色文字、深青主色、小面积朱砂点缀。入口留白，工作时出现可滚动的混合网格。输入框随数据、写作、规划调整形态；状态以简短标签呈现，诊断放在折叠面板。组件用轻位移和透明度进场，遵守 reduced-motion；文本编辑期间不重建编辑 DOM。

## 验收

- 复合目的同时保留多个能力，依赖顺序确定。
- 没有数据的统计阻塞，演示数据有明确标签。
- 发送幂等、并发受限、取消/失败/重启可见且不伪造完成。
- 文稿编辑、任务勾选、固定、刷新恢复、工作区路由、导出可用。
- 真实 KEV 与真实生成接口分别验证，失败时保留本地产物并明确原因。
