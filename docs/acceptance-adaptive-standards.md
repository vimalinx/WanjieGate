## 本轮源码交付

- 同一编辑节点扩展为持续文稿；标题、版本化保存、光标和草稿恢复；导出、插入撤销、大纲、独立笔记。
- 引用、图片、行情独立组合；无排他模式按钮；真实来源摘要、图片导入和原生拖拽接口。
- 有界页面内容输入、独立 JEV 分数、接受样本滞回、人工固定/收起、收起目标 rail。
- 对象多 Intent / Role 引用、显式与计算集合、声明式查询、上下文投影与来源；共享读取不扩大写权。
- 有限角色选择信号经 Policy 建立计算关系；用户明确关系与执行依赖优先。
- 统一语义动效控制器、稳定身份、可中断与减少动态效果；组件靠近、收起、恢复、拖动落位已接线。
- 模块 Manifest、Schema、脚手架、摘要安装锁、目录编译、可信生命周期与 provider 接入。
- 单机批量 DAG：最多 1000 个任务、1–3 并发、持久提交日志、依赖失败跳过、未知结果不重放。
- 经后续用户明确授权，浏览器默认开启真实 JEV 自动协助；有效输入或恢复时授予有次数/时限的 L0 网络能力。历史抽屉可暂停。

## 用户自行试用的顺序

1. 空白入口直接写正文，无需点击“文稿”：原输入展开为编辑器，文字/光标应保留，辅助材料按需要出现。
2. 固定一个块，再改写主题：它应保留位置；手动收起后高分不得让它自行回来。
3. 引用/行情与正文共存，拖引用进入正文，再刷新确认保存。
4. 两个空间引用同一个共享对象、设置不同角色；取消共享后另一空间不能继续读取当前正文。
5. 扩展先 check/install，再刷新；批量先看 plan，填正确 Intent 并明确 --run 后才执行。
