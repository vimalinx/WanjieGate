# 万界门黑客松 Demo 设计

## 目标与确认状态

面向黑客松评委，展示自然语言如何变成可选择、可组合的行动。产品覆盖学习、生活和工作入口，重点完成“资料到写作”和“股票到研究卡片”。开发预算为 1 小时，队员整合和展示准备另有时间。在本机浏览器运行。

本文件整理自 2026-09-27 当前会话。用户已选择中央胶囊、边缘泛光、浮动泡泡、拖拽融合、歧义时提供选项，以及两个候选管理按钮。用户授权复用本地 OpenRouter 密钥调用 Jev 和生成模型。书面规格待用户审阅；本文不表示产品已实现。

作者为本会话用户，具体署名 unknown；Codex 负责整理和技术建议。关联 IDEA-0001，保留已有 Runtime 方向，不推定 vimalinx 与 kanemaverick 对本方案形成共同意见。

## 产品范围

| 本轮交付 | 具体结果 |
|---|---|
| 多场景入口 | 写作、查资料、阅读、学习、生活规划、股票等真实资源或动作候选 |
| 中央胶囊 | 固定输入位置；理解状态改变时边缘柔光变化；右端放“更多灵感”和“换一批” |
| 浮动泡泡 | 轻缓漂移、拖动、预览、选择、融合与拆开 |
| 组合泡泡 | 内含有限步骤，可展开、继续组合、运行和查看结果 |
| 资料到写作 | 读取资料，生成带来源编号的可编辑草稿 |
| 股票到研究卡片 | 获取行情，整理已取得的资料，生成待核实问题 |
| 判断证据 | 可展开查看实际 Jev 模型、选择结果、概率及端到端耗时 |

本轮不包含通用工作流编辑器、循环与任意分支、交易执行、完整桌面应用控制、在线部署和跨设备同步。网页入口、预置资料和读取指定链接作为资料获取方式；通用网页搜索 API 留给后续整合。

## 视觉与交互

胶囊位于画布中央，输入位置保持稳定。轮廓完整，通过边缘柔光表达正在判断和候选就绪。演示草图中的循环动画仅用于选型，产品按状态播放，不反复开合。

泡泡围绕胶囊分布，避开输入区域和已有组合。漂移幅度小，悬停、键盘聚焦和拖动时停止漂移。候选文字保持清晰，不用模糊程度表示置信度。尊重系统减少动画设置，并提供按钮作为拖拽的替代操作。

以下数量是本版建议默认值，随本规格一并审阅：首次最多显示 6 个候选；“更多灵感”每次最多补充 3 个；画布最多保留 12 个未合并候选。达到上限时提示先移除候选或换一批，不挤走用户选择。无合适候选时允许少显示或不显示。

### 更多灵感与换一批

- “更多灵感”：保留现有泡泡及位置，从尚未展示的有效候选中补充。候选不足时提示，没有数据则不编造资源。
- “换一批”：只替换未选中的候选，保留选中、用户拖动固定及已合并的泡泡。优先避开本轮已展示项。
- 判断期间同类按钮显示等待状态，避免重复请求。刷新失败保留当前画面。
- 输入变化更新临时候选，不修改用户已经组成的流程。明确的新约束若与组合冲突，标出冲突，并在运行前要求用户调整。

### 拖拽融合

拖近另一泡泡后显示组合预览。短暂停留后请求一次 Jev 判断，避免每个拖动帧调用。请求携带输入版本、两个泡泡身份和版本；泡泡离开、输入改变或任一成员改变后，旧判断不得应用。

程序根据输入输出类型列出可执行的组合选项。Jev Choice 根据用户目的从这些选项中选择：资料供给动作、汇集资料、对比资料、顺序执行，或信息不足。资料集合可以只组织灵感，尚未配置动作时显示“资料集合”，不显示可执行承诺。

明确时松手形成组合泡泡；尚在判断时显示短暂等待；有歧义时显示最多 3 个具体组合选项。服务失败时恢复原泡泡，保留手动选择已支持组合的入口，不伪装成 Jev 判断。

是否明确由可配置的最高概率、前两项差距和约束检查共同决定。阈值必须用本 Demo 的中文样例校准；不把模型 confidence 当作正确率或执行许可。实现计划需给出初始阈值与验收样例。

组合泡泡保留成员身份、顺序、选用的组合方式与预览说明。支持点击展开、拆开和继续合并。首版只支持资料集合和最多 4 个执行步骤的有向无环序列。类型不匹配、循环或超限时显示原因，不丢失原对象。组合标题使用动作模板与对象名称，不额外等待生成模型命名。

融合只改变组织方式；点击“运行”才调用执行能力。重复点击不重复执行同一任务。结果显示在展开面板，画布与输入保留。

## Jev 的职责与数据流

输入提交中文字词后，发送当前文本、必要上下文和真实候选摘要。一个页面最多保留一个进行中的候选判断，期间只保留最新待处理输入。清空、切换场景或刷新候选都会增加版本，过时响应不能覆盖新状态。

候选相关性使用独立 Noul 或描述明确的 Score，支持多个场景同时成立。组合含义使用 Choice，只提供程序实际支持的选项，包含无匹配或信息不足。多个独立问题可以放在一次请求中；依赖实际网页内容或行情的判断必须等数据返回。

基本过程：输入 → 获取候选 → Jev 判断 → 稳定展示 → 拖拽组合 → Jev 选择组合关系 → 程序校验 → 用户运行 → Runtime 执行 → 展示结果。

## 两条执行流程

### 资料到写作

用户选择真实预置来源、已有资料或粘贴网页链接。网页读取成功后生成资料对象，包含标题、URL、实际取得的正文和读取状态。打开搜索页仅是外部入口，不假装自动取得搜索结果。

资料泡泡与写作泡泡融合后，程序将选定资料提供给生成模型。草稿带来源编号及可点击来源列表；不把未读取的网页当作已引用证据。正文可编辑、复制和导出 Markdown。

输入“不要代写”时撤下正文生成候选，可继续提供资料集合或空白写作动作。已有写作组合保留但提示约束冲突，不自动执行代写。

### 股票到研究卡片

沿用行情适配，展示证券名称、代码、价格、涨跌、来源、报价时间和可用走势。本文验证只覆盖腾讯上证指数接口；美股、港股和名称匹配需在实施时单独检查。

行情与研究动作融合后，生成价格概览、已提供资料摘要和待核实问题。没有新闻数据时明确写“尚未添加新闻资料”，不生成未经检索的最新消息。用户可以继续合并实际读取的网页资料。卡片支持编辑和 Markdown 导出，不执行交易。

## 架构与接口

复用 Python 标准库服务、原生 ES Modules、Runtime 任务与 Artifact 存储。新增泡泡前端作为产品入口，保留现有工作台可访问。具体路由与文件划分在实施计划中固定。

| 单元 | 职责与依赖 |
|---|---|
| 候选目录 | 注册资源、动作、来源与类型；提供可执行能力标识 |
| Jev 适配 | 服务端请求 Decisions API；校验答案；提供版本、耗时和真实结果 |
| 泡泡状态 | 管理身份、位置、选择、集合与组合；独立于动画 |
| 画布与胶囊 | 渲染、漂移、拖动、融合反馈、按钮及展开面板 |
| 组合校验 | 根据真实类型构造 Choice 选项并校验执行序列 |
| 执行适配 | 将组合交给现有任务框架，复用网页读取与行情能力，新增生成提供者 |

Jev 接口固定为 `https://openrouter.ai/api/alpha/decisions`，模型为 `typesafe/jev-1.13`，复用用户提供脚本的 `state`、`questions` 和 `criteria` 结构。它不是 Chat Completions。

服务端从用户指定的 `/Users/a1-6/Documents/ChatGPT/JEV 黑客松/.env` 读取 `OPENROUTER_API_KEY`，通过本地配置指定路径；不复制密钥到源码、浏览器或 Git，不修改该项目。环境变量可以覆盖本地配置。

正文生成单独使用 OpenRouter 生成接口与可配置模型。实施时先核对账户可用模型并以短请求验证，记录实际模型名称与费用信息；不得将 Jev 当作文本生成模型。用户已授权相应 API 调用费用。

现有语义能力的网络与费用声明需随云端接入更新，继续使用 Runtime 的授权与任务边界。开发时配置一次明确的 Demo 授权，后续操作不重复弹出已授权事项。

## 错误处理与验收

模型或网络失败保留输入、选择与组合，显示失败步骤并允许手动重试。任务部分成功时保留真实产物。取消阻止后续步骤，不声称撤回已经发出的上游请求。服务端日志与前端调试面板不暴露密钥。

验收覆盖以下行为：

1. 连续中文输入、否定、改口与复合意图，最新输入始终优先。
2. 拖拽、悬停、键盘操作与减少动画设置不干扰输入。
3. 更多灵感不移除既有泡泡；换一批保留用户选择及合并结果；没有候选时如实提示。
4. 明确融合、歧义选择、无匹配、拆开、继续组合及失效响应保护。
5. 真实 Jev 判断与手动选择可区分；检查已选动作没有违反用户否定约束。
6. 资料读取到草稿，以及行情到研究卡片，两条实际请求流程可完成并导出。
7. 断网、模型失败、重复运行、过期行情与缺少新闻时，界面状态和文案准确。

对版本、组合和请求去重运行针对性测试；浏览器验证实际交互；少量真实请求确认 API 与两条流程。验收记录分别标明受控测试和外部服务实测。
