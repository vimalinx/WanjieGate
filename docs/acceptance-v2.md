## 已发现并处理

- 原单选意图无法形成复合任务：改为独立能力分数 + 显式选择 + 依赖图。
- 预览预算曾只影响预览：现在后端冻结实际组件选择，渲染按产物选择执行。
- SQLite 连接最初未及时关闭：改为显式 context manager，回归无连接泄漏警告。
- 中文输入法、清空与旧决策竞态：组合期间不发送；序列和 AbortController 丢弃陈旧结果。
- 网络未知发送：浏览器保留发送编号，刷新查询同一提交；不会静默生成第二个编号重发。
- 模型有时返回超过要求的行动数量：新增明确条数约束，离线验证通过。历史真实响应保留，不追改为更漂亮的证据。

## 外部接口观察

Mistral 返回限流；LLM7 的 GLM 探针返回上游暂不可用；BAI 的 Qwen 调用返回额度不足；GMI 返回余额不足。均保留单次调用回执，没有修改其他项目的账号、池或服务配置。早期 Nemo 虽能返回结果，但中文质量不足，没有选作默认。

## 尚有限制

生成按阶段返回，尚非逐 token 展示；云端时延与可用性仍有波动。模型文本是可编辑草稿，来源不足时仍可能提出未经数据证明的推断。任务数量约束已经由代码处理，但正文篇幅和推断质量尚不是严格验收器。

当前只有分析、写作、规划、回答和笔记执行器；没有接入外部社交、监控或消息发送。取消阻止后续步骤与写回，不能撤回已发送的上游请求。生产级多用户认证、共享空间和公网部署不在本次本机范围。
