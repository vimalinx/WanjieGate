# 泡泡 Demo 验收与交接

2026-09-27，Codex 在 `codex/bubble-demo` 分支实现。本记录仅描述 WanjieGate 的实测范围，不代表外部项目或双方共同评审。

## 启动与演示

按根目录 README 的环境变量示例启动，进入 `/demo`。使用 Python 标准库与原生 ES Modules，无安装前端依赖的步骤。密钥文件由 `WANJIE_ENV_FILE` 指向已有 Jev 项目的 `.env`；前端只访问本机同源 Runtime。

连接设置授权当前 Intent 的 Jev、生成、网页、行情能力，期限 1 小时，上限 100 次能力调用。授权不会自动续期。Jev 和生成收费；仅整理、拆开、撤销不生成正文。

**资料写作：** 添加两份阅读笔记，输入“根据两份阅读笔记写一篇 200 字的读书感想，引用两个来源”。将资料拖在一起，必要时选择“汇集”，再与“写一篇草稿”连接。打开组合核对来源和读取范围，点击运行。完成后在“我的产物”编辑、复制或导出 Markdown。来源列表记录实际 Artifact ID、版本、正文与来源信息。

**股票研究：** 输入“查询上证指数 sh000001 的行情，整理一张研究卡片，标注报价时间”。把“查询股票行情”与“整理研究卡片”组合，核对后运行。演示时以接口返回的报价时间为准；周末、休市或供应商缓存可能返回旧日期。未添加新闻时，结果明确写出资料缺失。

可以通过详情中的选择框完成组合，不必依赖拖拽。Esc 关闭详情；减少动态效果的系统设置会停用漂移。窄屏详情覆盖画布，关闭后继续操作。

## 实现边界

- 没有通用搜索 API。预置链接与用户粘贴的 HTTPS 链接可在执行时读取；搜索入口只打开外部网页，不伪装成已读取资料。
- 保存采用服务端版本校验；冲突保留浏览器副本并提示。首版没有多人同时编辑时的自动合并。
- 行情沿用已有供应商，不保证交易时效；卡片用于展示资料组织过程。
- 候选不足 6 个时按真实判断显示较少泡泡；增加或刷新没有新方向时明确提示。
- 最多 4 个执行步骤；组合可递归组织。来源预算默认 12000 字符，超出时提示改用 1200 字符片段。
- 本机服务只监听 loopback。本轮没有部署公网、推送、合并到主分支或集成其他队员服务。

## 开发取舍记录

1. 使用受管理的独立 worktree，保留原目录未提交的设计研究。代价是整合时需要切换或合并分支。
2. 使用原生 Pointer Events 与稳定锚点，不加入物理库。代价是漂移属于视觉效果，没有自由碰撞模拟。
3. 已安装 skill 的任务辅助脚本执行权限不完整，使用手动 ledger，未修改 skill 文件。代价是进度登记不由辅助脚本自动核验。
4. 本机代理截获 localhost 测试，回归仅为 loopback 设置 NO_PROXY，远程 API 保留代理。代价是其他环境可能需要自己的代理设置。
5. 画布冻结与执行器在同一模块实现，旧 workflow 契约保持原样。代价是 `bubbles.py` 同时承担编译和执行，后续可按复杂度拆分。
6. 原 CommandClient 已支持显式 ID，只新增包装层，未重复改造。代价是继续依赖既有 Runtime 命令契约。
7. OpenAI mini 受地区限制，改用实测成功的 DeepSeek；模型可配置。代价是生成风格与成本不同。
8. 真实测试发现索引式候选问题歧义，改为每题写明需求与候选含义。代价是输入 token 增加，换来本次样例的正确对应；阈值仍属 Demo 初始值。

## 独立审查与修复

由一个独立 reviewer 只读审查完整分支，未发现 Critical 问题。发现的 4 项 Important 恢复问题已在一次修复中处理，并经过失败到通过的回归：

- 拖动期间超时或输入变化后松手：核对交互身份、输入与成员版本，失效时复原，不再打开无请求的等待框。
- 请求未受理且响应不明：提供“重发本次运行”，复用保存的载荷及原 runId；已受理的任务只核对。中断的排队任务支持显式再次运行。
- 编辑原始资料：详情和组合成员提供“使用资料最新版本”，旧运行来源快照保留。
- Jev 判断失败：保留两个泡泡，提供标为“用户选择”的有限手动选项，继续校验否定约束与 4 步上限。

补充浏览器检查发现多个组合可能占据同一默认锚点，已增加布局去重，并补回归。来源版本更新、手动降级选择、两个真实流程的最终产物均已在浏览器复验。

最终回归为 76 个 Python 用例（1 个环境依赖跳过）、原有 4 组 Node 检查及 6 个恢复测试；不触发外部 API。

暂缓两项低优先级改进：部分前端函数排版较紧凑；键盘聚焦泡泡尚未单独暂停漂移（悬停、拖动和系统减少动态效果已支持）。

审查中明确保留的边界：跨项目集成不在本轮范围，代价是仍需队员整合；通用搜索、公网部署与多人编辑未包含，代价是本机演示功能边界；少量实测不作为统计准确率证据，后续准确率需要独立样本评估。

## 动效对照复核与更正（2026-09-27，Codex）

用户反馈融合动效不可见后，核对两张实际 Demo 页：减少动画均未开启；另一张页面仍为旧脚本（没有减少动画按钮，外部入口仍是 button），并显示保存版本冲突，网站入口覆盖资料泡泡。不能把旧页和遮挡视为完整原因；本项目此前验收没有证明参考动效达到视觉要求。

对照 Paper.js Meta Balls 公开示例源码，当前 `motion.mjs` 是简化的中点控制 Bézier 连接，没有示例中的相交角、切线方向手柄和重叠几何处理；外壳仍是各自的圆，尚未形成完整液体轮廓。Bubble 方向已做渐变质感、不同周期的 8px 上下漂浮和指针跟随；弹性只含固定拖动缩放与融合回弹，不等同于完整柔软手感。以上均应标为部分近似实现，不能称为参考效果完整验收。

本次修复确定的问题：松手清理拖拽时，连接原先立即隐藏；现在匹配/选择期间重新绑定两个可见成员的连接，完成融合时连接随成员收拢淡出。渐变方向使用两圆中心坐标，融合时长调整为 650ms；连接动画用代际标识避免覆盖后续拖拽。新增受控 DOM 回归验证匹配期间连接保留、正常模式触发两个成员与共同外壳动画、动画结束清理；这证明生命周期行为，不替代实际浏览器的完整视觉验收。参考页在内置浏览器加载超时，本轮参考几何对照依据公开示例源码。
